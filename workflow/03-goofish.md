# 03 · 闲鱼上架 SOP

## 入口

`https://www.goofish.com/publish`（需登录，卖家：Goth三叶草）

## 固定配置

| 项 | 值 |
|---|---|
| 价格 | ¥7.7（原价 12） |
| 分类 | **电子资料**（描述以「手机壁纸」开头是映射关键） |
| 发货 | 24 小时发货、包邮、无需邮寄 |
| 图片 | 2 张：`*_wall_pub.jpg` + `*_sq_pub.jpg` |

## 步骤（浏览器自动化）

1. 打开 publish 页，等 4s
2. 点主图位 (145,330) → `upload_file` 壁纸 pub 图
3. 点缩略图位 (235,330) → `upload_file` 方形 pub 图
4. 点 (970,50) 关预览
5. JS 写描述（contenteditable + execCommand insertText）→ 模板见 templates/goofish_desc.txt
6. JS 打开分类下拉 `#rc_select_0` mousedown → 遍历 `.ant-select-item-option` 点「电子资料」
7. 滚到底 → 填价 7.7 / 原价 12 → 点发布
8. **成功标志**：URL 变为 `item?id=<ID>`，回读商品详情页

## 描述模板（复制即用）

> 4K超清热门游戏人气角色手机壁纸图集2张高清原图。XXX竖屏壁纸+同款方形手机壳素材，可做手机壁纸，也可定制实物手机壳。数字商品自动发货，拍下即发邮箱。

## 踩坑

- 分类映射到实物类目（徽章/钥匙扣等）→ 网页版「暂不支持发布」→ 重载页面 + 保证描述含「手机壁纸」重新映射
- 分类下拉选项：优先「电子资料」，不在选项时换「电子壁纸」
- 发布按钮有时第一次点击不生效 → 滚到底后重新 click / click_xy(500,930) 重试
- 分类「电子资料」文字必须完全匹配（`=== '电子资料'`）
