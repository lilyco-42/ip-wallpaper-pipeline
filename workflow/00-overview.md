# 00 · 流水线总览与排期

## 单角色循环（一份商品 = 一轮循环）

| 阶段 | 产出 | 用时 | 工具 |
|---|---|---|---|
| ① 生图 | 壁纸 9:16 + 方形 1:1（各 1 张） | ~4-6 min | ChatGPT / Gemini |
| ② 4K | `*_wall_4k.jpg` 2160×3840 + `*_sq_4k.jpg` 3840×3840 + `*_pub.jpg` 1080px | ~30 s | tools/upscale4k.py + make_pub.py |
| ③ 闲鱼 | 商品 ¥7.7（分类=电子资料） | ~2 min | goofish.com/publish |
| ④ 小红书 | 笔记 1 篇（标题≤20字 + #话题） | ~2 min | creator.xiaohongshu.com |
| ⑤ 夸克 | 上传 4K 原图 + 永久分享 | ~1 min | tools/kuake_upload.ps1 |
| ⑥ 台账 | listings.csv 登记 | ~10 s | 手动/脚本 |

**合计 ≈ 12-15 分钟 / 角色**，可并行流水线（一个角色在等生图时，另一个角色在上架）。

## 排期建议（日更 5-8 角色）

- 上午：批量生图（GPT 3 角色 + Gemini 3 角色，穿插轮询避免限流）
- 下午：批量 4K → 批量闲鱼 → 批量小红书 → 夸克归档
- 每 3 天：检查小红书评论区/点赞，淘汰低热度角色，加产高热度角色

## 质量控制（每轮必做）

1. 4K 后用 Read 回读 1 张确认画质（锐化不过度、无糊脸）
2. 闲鱼发布后确认跳转商品详情页（URL 含 `item?id=`）才算成功
3. 小红书发布后确认回到「上传视频」页（发布成功标志）
4. 夸克上传后确认「已完成」计数增加
